SECTION 1: IOT SENSOR APIS (/api/v1/sensors/*)
Authentication: Sensor Bearer Token ("Authorization: Bearer <token>")
================================================================================

--------------------------------------------------------------------------------
1.1 Register Sensor (Auto-Approval)
--------------------------------------------------------------------------------
Description: Registers a new ESP32 sensor. If approved, immediately returns the
             Bearer token.
Method     : POST
URL        : {{baseUrl}}/api/v1/sensors/register
Headers    :
  Content-Type: application/json

Body (raw JSON):
{
  "deviceId": "ESP32-DEVICE-001",
  "sensorVersion": "1.0.0",
  "firmwareVersion": "4.0.0",
  "hardwareModel": "ESP32-DevKit-V1",
  "metadata": {
    "location": "Testing Lab"
  }
}

Expected Response (201 Created):
{
  "success": true,
  "status": "AUTO_APPROVED",
  "deviceId": "ESP32-DEVICE-001",
  "token": "4f8a92b...64_hex_characters...",
  "requestId": "req-1792476058771",
  "message": "Sensor automatically approved! Store your Bearer token securely."
}

Conflict Response (409 Conflict):
{
  "success": false,
  "error": "Sensor already registered and ACTIVE",
  "status": 409
}


--------------------------------------------------------------------------------
1.2 Sensor Heartbeat / Ping
--------------------------------------------------------------------------------
Description: Sends periodic telemetry ping (heap, RSSI, uptime) and automatically
             synchronizes the latest sensor_version with the admin website.
Method     : POST
URL        : {{baseUrl}}/api/v1/sensors/heartbeat
Headers    :
  Content-Type: application/json
  Authorization: Bearer {{sensorToken}}
  X-Sensor-ID: {{deviceId}}

Body (raw JSON):
{
  "deviceId": "ESP32-DEVICE-001",
  "sensorVersion": "1.1.1",
  "firmwareVersion": "4.0.0",
  "hardwareModel": "ESP32-DevKit-V1",
  "metadata": {
    "freeHeap": 184320,
    "rssi": -55,
    "uptime": 3600
  }
}

Expected Response (200 OK):
{
  "success": true,
  "data": {
    "ok": true,
    "deviceId": "ESP32-DEVICE-001",
    "sensorStatus": "ACTIVE",
    "serverTime": "2026-11-11T05:35:00+00:00",
    "timestamp": "2026-11-11T05:35:00+00:00"
  },
  "message": "Success"
}


--------------------------------------------------------------------------------
1.3 Check Configuration Version
--------------------------------------------------------------------------------
Description: Checks if an OTA configuration update is available on the server.
Method     : POST
URL        : {{baseUrl}}/api/v1/sensors/version-check
Headers    :
  Content-Type: application/json
  Authorization: Bearer {{sensorToken}}
  X-Sensor-ID: {{deviceId}}

Body (raw JSON):
{
  "currentVersion": "1.0.0"
}

Expected Response when Update Available (200 OK):
{
  "result": "UPDATE_AVAILABLE",
  "activeVersion": "1.1.1",
  "reportedVersion": "1.0.0",
  "downloadUrl": "/api/v1/sensors/configuration/download?deviceId=ESP32-DEVICE-001"
}

Expected Response when Current (200 OK):
{
  "result": "CURRENT",
  "activeVersion": "1.1.1",
  "reportedVersion": "1.1.1",
  "downloadUrl": null
}


--------------------------------------------------------------------------------
1.4 Download Active Configuration File
--------------------------------------------------------------------------------
Description: Streams the active JSON configuration file to the device.
             Automatically updates sensor_version in database to match active.
Method     : GET
URL        : {{baseUrl}}/api/v1/sensors/configuration/download?deviceId={{deviceId}}
Headers    :
  Authorization: Bearer {{sensorToken}}
  X-Sensor-ID: {{deviceId}}

Expected Response (200 OK):
Response Headers:
  Content-Type: application/json
  Content-Disposition: attachment; filename="sensor_config_v1.1.1.json"
  X-Config-Version: 1.1.1
Body:
  <Raw JSON content of active configuration file>


--------------------------------------------------------------------------------
1.5 Upload Telemetry File (Max 100 MB)
--------------------------------------------------------------------------------
Description: Ingests sensor data file (CSV / binary), stores to disk, verifies
             SHA-256 checksum, and updates device upload count & total bytes.
Method     : POST
URL        : {{baseUrl}}/api/v1/sensors/upload
Headers    :
  Authorization: Bearer {{sensorToken}}
  X-Sensor-ID: {{deviceId}}
  X-Sensor-Version: 1.1.1

Body (form-data):
  file : [Select file from disk, e.g. telemetry.csv]

Expected Response (201 Created):
{
  "success": true,
  "uploadId": "UPL-20261111-A8F2",
  "originalFileName": "telemetry.csv",
  "fileSizeBytes": 1024,
  "checksum": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855",
  "uploadedAt": "2026-11-11T05:35:00+00:00"
}

--------------------------------------------------------------------------------
2.1 Portal User Login
--------------------------------------------------------------------------------
Description: Authenticates public user to unlock the website homepage & upload views.
             Default Credentials: user / password
Method     : POST
URL        : {{baseUrl}}/api/user/login
Headers    :
  Content-Type: application/json

Body (raw JSON):
{
  "username": "user",
  "password": "password"
}

Expected Response (200 OK):
Sets-Cookie: fv_portal_session=<session_id>; Path=/; HttpOnly; SameSite=Lax
{
  "success": true,
  "data": {
    "user": {
      "id": "user-portal-0001",
      "username": "user",
      "role": "USER"
    },
    "message": "Portal authenticated successfully"
  },
  "message": "Unlocked successfully"
}

             immediately on subsequent login.

URL        : {{baseUrl}}/api/admin/settings/admin-credentials
